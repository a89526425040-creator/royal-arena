# Royal Arena

Мобильная merge tower defense игра на Godot 4.4.

## Уже реализовано
- Поле 3×5 (15 ячеек).
- Призыв юнитов за золото.
- Слияние двух одинаковых юнитов в юнита следующего ранга.
- Автоматические атаки и волны монстров.
- Награды за победы над монстрами.
- Сенсорный интерфейс и портретная ориентация.

## Сборка Android
Каждый push в `main` запускает GitHub Actions workflow **Build Royal Arena Android APK**.
APK появится в разделе Artifacts завершённого запуска.

## План
1. Игровой баланс, эффекты, анимации и разные типы юнитов.
2. Экран колоды и улучшения.
3. PvP и кооперативный режим с серверной синхронизацией.
4. Звук, сохранения и финальная полировка.
